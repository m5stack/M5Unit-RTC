◆ charge

bool m5::unit::UnitRX8130::config_t::charge {false}

Enable charging of the backup battery from VDD (CHGEN)

Warning
Enable it only when a rechargeable battery or a supercapacitor is on VBAT. Charging a primary cell can make it leak or burst
Note
Built-in RX8130CE of M5Stack boards (from the published schematics):
  • Tab5, StampPLC: supercapacitor / rechargeable cell through 1 kOhm, set true to keep the backup charged (true by default in Tab5BuiltinRTC)
  • ToughC5: CR2032 primary cell directly on VBAT, keep false
  • StopWatch, PaperColor, PaperMono: no backup cell, no effect
The default is false (the power-on state of the chip). begin() always writes CHGEN, so false also stops charging enabled before (e.g. by M5Unified)
Charging works only with power_switch (INIEN) enabled
