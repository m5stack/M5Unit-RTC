Alarm
Note
About IRQ/Alarm/Timer/Update: These functions configure the RX8130 alarm, wakeup timer and time update interrupt. When triggered, the chip drives its /IRQ pin (open-drain, active LOW).
Two modes are supported via config_t:
  • Polling mode (default, polling=true): update() periodically reads the flag register via I2C and invokes the callback.
  • Hardware interrupt mode (polling=false, int_pin set): the ISR sets an internal flag; update() detects it and invokes the callback. Requires a connection from the /IRQ pin to a host GPIO.
In both modes, callbacks are called from update(), never from an ISR context. Set them in config_t before calling begin(). update() does nothing without callbacks.
update() clears only the flags that have a callback; the others are left for the read functions. In the hardware interrupt mode a flag with its interrupt enabled is cleared too (AF holds /IRQ low, and no further interrupt would arrive).
writeAlarm(), writeAlarmWeekdays() and writeTimer() do not change the interrupt enable bits (AIE / TIE), except that an alarm without any field disables AIE (see writeAlarm()). The flags are set either way, so the polling mode needs no enable bit. To drive /IRQ (the hardware interrupt mode, or a wakeup through the board), enable it with writeAlarmInterrupt() / writeTimerInterrupt() / writeUpdateInterrupt(). The M5Unified compatible setAlarmIRQ() / setTimerIRQ() enable it, as M5Unified does.
Warning
M5Stack Tab5: the /IRQ of the built-in RX8130CE drives the power management MCU (E_TRG). A short-period timer interrupt left enabled (TIE=1) can make the Tab5 unbootable: every power-on is cut before setup() runs, and the RX8130CE keeps running on the backup cell, so removing USB and the battery does not clear it. Do not enable the timer (TIE) or the update (UIE) interrupt on Tab5: use Tab5BuiltinRTC, which refuses them (setTimerIRQ() with a positive period too, as M5Unified does). An alarm interrupt (AIE=1) holds /IRQ low until AF is cleared: it turns the Tab5 on while it is off (the wakeup used by M5Unified timerSleep(time)), but can turn it off while it is running.

Detailed Description

Real-time clock using Epson RX8130CE.

The RX8130CE is built into several M5Stack controllers (Tab5, StampPLC, PaperColor, etc.) on the internal I2C bus. Add it with the internal bus, e.g. Units.add(rtc, M5.In_I2C), and set internal_rtc = false in M5.config() so that M5.Rtc does not use the same chip. For the Tab5 use Tab5BuiltinRTC (see the IRQ notes).

Note
The year range is 2000-2099 (the chip has no century bit)
