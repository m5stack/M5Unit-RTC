Alarm/Timer
Note
About IRQ/Alarm/Timer: These functions configure the PCF8563 chip's internal alarm/timer registers and interrupt flags via I2C. When triggered, the chip drives its INT pin (open-drain, active LOW).
The INT pin is not wired on standard GROVE/Port A/B/C connectors (4-pin: GND, VCC, SDA, SCL only).
Two modes are supported via config_t:
  • Polling mode (default, polling=true, or int_pin < 0): update() reads the IRQ status register via I2C every polling_interval ms and invokes the callback. Works without the INT pin (GROVE compatible).
  • Hardware interrupt mode (polling=false, int_pin set): begin() adds an ESP-IDF GPIO ISR (gpio_isr_handler_add) on the specified pin and fails if it cannot. The ISR sets an internal flag; update() detects it and invokes the callback. Requires a direct connection from the PCF8563 INT pin to a host GPIO.
In both modes, callbacks (on_alarm / on_timer) are called from update(), never from an ISR context. Set them in config_t before calling begin(). update() does nothing without callbacks.
update() clears only the flags that have a callback; the others are left for readAlarmFlag() / readTimerFlag(). In the hardware interrupt mode a flag with its interrupt enabled is cleared too, since it would hold INT low and no further interrupt would arrive.
A flag is cleared by read-modify-write of CONTROL2, writing the other flag back as read (on the Unit RTC writing 1 sets a flag, unlike the datasheets). The other flag set between the read and the write is lost.
writeAlarm() and writeTimer() do not change the interrupt enable bits (AIE / TIE). The flags are set either way, so the polling mode needs no enable bit. To drive INT (the hardware interrupt mode, or a wakeup through the board), enable it with writeAlarmInterrupt() / writeTimerInterrupt(). The M5Unified compatible setAlarmIRQ() / setTimerIRQ() enable it, as M5Unified does.

◆ writeTimer() [1/2]

uint32_t m5::unit::UnitPCF8563::writeTimer ( const uint32_t msec)

Set the countdown timer with a millisecond period.

Parameters
msecPeriod in milliseconds, rounded to seconds (0 or less than 500 to disable)
Returns
Actual period in milliseconds (0 if disabled or on failure)
Note
The timer repeats: the PCF8563 reloads the countdown every period and sets TF each time (it has no one-shot mode). Stop it with writeTimer(0), e.g. in the on_timer callback.
Automatically selects Hz1 (< 270s) or HzPM (>= 270s) clock source. Clears the timer flag (the alarm flag is kept) and starts the timer. The timer interrupt (TIE) and the /INT output mode (TI_TP) are kept; enable TIE with writeTimerInterrupt() to drive INT. Maximum: 255 minutes (15,300,000 ms).
Only the first period is shorter. The Unit RTC chip decrements the countdown as soon as the timer starts and counts on the seconds tick, so with the 1 Hz source the first TF comes after more than N-2 and at most N-1 seconds (N = period in seconds), then every N seconds. The NXP PCF8563 also has an uncertain first period ((N-1) + 1/64 s to N + 1/64 s with the 1 Hz source, NXP UM10301 chapter 17).
